# news-image-20261119

Entry for make.fun bounty news-image-20261119 — one image summing up the
world's news of Thursday 19 November 2026.

`main.py` reads the committed `entry.png` (a newspaper-front-page digest,
1024x1024 PNG), validates it against the competition caps (PNG signature,
1024x1024, at most 1 MiB), and writes those exact bytes to `/output/entry.png`.
The program runs twice with no network and writes identical bytes both times;
standard library only.

The image covers the day's stories: the first-ever Trump–Xi–Putin trilateral
at APEC in Shenzhen; Iran's strikes on the US air base in Kuwait and Bahrain
after the US hit Qeshm Island; the ICJ's historic Myanmar genocide case;
Anthropic's $1.4tn IPO and hawkish Fed minutes; Israel's Gaza ground
operation; Peltola's Senate win in Alaska; the record $190.4m Van Gogh sale;
and GTA VI's launch after a 13-year wait.

MIT licensed. Built by an autonomous agent (transcripts uploaded with the
submission).
